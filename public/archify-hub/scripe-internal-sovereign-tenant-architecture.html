How will SCRIPE run as an internal sovereign tenant across Production and Development?

Long image

A

Answer

SCRIPE runs as a dedicated internal tenant (Code = "SCRIPE", subdomain scripe.admin.scripe.org) backed by explicit TenantKind.Internal and EditionScope.Internal flags, separated from Platform Root (superadmin) via a distinct verified company email (admin-seif@scripe.org).

  1. Separate emails eliminate shared-email lockouts and OTP/magic-link collisions without delaying delivery for a login redesign.
  2. Explicit TenantKind and EditionScope enums preserve Edition.IsSystem, avoid Edition.IsFree collisions, and exclude internal records from commercial KPIs and Stripe Connect.
  3. First-create-only complex bootstrap validation enforces MustChangePassword = true in Production and Staging without breaking restarts or automated test suites.
  4. Capacity quotas use -1 with lock-free short-circuiting while security, SLA, and upload limits remain capped.

  1. ScripeInternalSeeder ↗

    Upserts SCRIPE tenant, tenant settings, role, and initial scripeadmin before RoleAndAdminSeeder runs.

  2. RoleAndAdminSeeder ↗

    Syncs tenant permissions onto T_SCRIPE_SA, creates scripe.admin.scripe.org, and keeps superadmin scoped to null TenantId.

  3. EntitlementsStartupSeeder ↗

    Seeds scripe-internal edition, assigns an active Lifetime subscription, and provisions lock-free Unlimited QuotaCounters.

  4. CRM + CustomFields ↗

    Paginates active tenants to create canonical pipelines, EGP settings, HQ lead routing, and AES encryption keys.

  5. Isolation & Triggers ↗

    Enforces DB triggers, soft-delete purge exclusions, signup blocks, and commercial KPI filters.

Restart Safety After Secret Rotation

Bootstrap secret checks execute solely inside the first-time existingAdmin == null branch. Subsequent restarts in Production succeed when bootstrap environment variables are cleared after onboarding. Test harnesses pass test secrets via TestWebApplicationFactory and complete password setup inside explicit test fixtures.
