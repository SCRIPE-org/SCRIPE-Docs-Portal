How does SCRIPE harden Sileo gooey toasts across Light, Dark, HC, and RTL?

Long image

A

Answer

SCRIPE integrates the SVG gooey physics Sileo toast engine (0.1.5) with reactive Nexus CSS custom properties (var(--nx-surface)), CSS transition isolation, tailwind-merge style composition, and DOM class-priority theme resolution.12

  1. Removing max-width: 100% from [data-sileo-header-stack] and [data-sileo-header-inner] restores accurate pill width measurement (223px–246px) instead of truncating titles inside 40px.3
  2. Excluding [data-sileo-svg] and <motion.rect data-sileo-body> from SCRIPE's global [data-animation="moderate"] 0.3s CSS transition prevents action buttons from overflowing the expanding SVG card.3
  3. Defaulting auto fills to "var(--nx-surface)" and omitting the theme prop on SileoBaseToaster eliminates OS-dark/app-light inversion and updates open toasts instantaneously on live theme switches.2
  4. Extracting sileo-config.ts, deduplicating RTL position normalization, and merging classes via twMerge eliminates circular imports, timer leaks, variant loss on toast.update, and semantic button border clashes.41

Why does [data-sileo-content] stay clipped until 250ms while SVG rects get 0ms CSS duration?

In Sileo, Framer Motion drives <motion.rect data-sileo-body> height per animation frame via inline styles, whereas CSS transitions reveal [data-sileo-content] via clip-path after 0.25s and hide it immediately (0s delay) on exit. Keeping 0ms CSS duration on SVG geometry prevents global moderate rules from lagging the backdrop behind the unclipped text or action button.3

Which Nexus tokens and reduced-motion rules govern every state?

Auto Theme Surface Fill
Uses "var(--nx-surface)" on SileoToaster so SVG cards mirror Light (#fff), Dark (#15181c), HC Light (#fff), and HC Dark (#0d0f12) without remounting
Explicit Theme Locks
Setting theme="light" or theme="dark" on SileoToaster pairs locked Light/Dark fill with LOCKED_LIGHT_SILEO_STYLES or LOCKED_DARK_SILEO_STYLES
High-Contrast Semantic Ink
Verified Light tokens use --success #126e43 (4.62:1 pill), --warning #765700 (4.95:1), and --info #0b5d85 (5.24:1); Dark uses #61d49a, #f2c94c, #7dd3fc
Motion Level & Reduced Motion
Both [data-animation="none"] and @media (prefers-reduced-motion: reduce) snap bodyH: 68, opacity: 1 with delay: 0s regardless of data-animation="moderate"
Official Docs Alignment
Tested and aligned against https://sileo.aaryan.design/docs for top-*/bottom-*, autopilot, fill, roundness, styles, button, update, and promise APIs 5
