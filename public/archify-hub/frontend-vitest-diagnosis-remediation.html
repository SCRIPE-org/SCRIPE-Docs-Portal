Why did 5 Vitest suites fail in SCRIPE-Frontend, and which bugs lived in Main App vs Tests?

Long image

A

Answer

Five Vitest suites (7 of 3301 tests) failed under scripe test frontend. One suite surfaced three Main App UI bugs alongside missing test mocks.12

  1. optionSet.wiring.test.ts failed purely because its text-slice end marker broke when commit a65306410 appended valid useMemo dependencies (vm.error, vm.items, vm.refresh) in CustomFieldListView.tsx.2
  2. VenueOverviewComponents.test.tsx and VenueOverviewView.test.tsx lacked @core/providers/i18n-provider mocks after unmounted useI18n() began returning defaultValue, which simultaneously exposed hardcoded English buttons, raw camelCase KPI fallbacks, and a mismatched dashboard label in the Main App.345
  3. Under 12-worker parallel CPU load, redundant monorepo file walks in use-restricted-fields.backendContract.test.ts (13275ms–14263ms per test) and heavy DOM tests in PipelineManagementView.test.tsx (18513ms) exceeded Vitest's default 15000ms limit.67

What three Main App defects did Venue Overview expose?

Inspecting the strings returned by defaultValue revealed three real bugs in production components that were previously hidden while unmounted useI18n() echoed translation keys.345

VenueOverviewHeader.tsx (Dead Store + Hardcoded English)
Removed unused useAppStore import (user, userName), added venueOverview.quickActions.blockTime ("Block Time" / "حظر وقت") and recordPayment ("Record Payment" / "تسجيل دفعة"), and replaced three hardcoded button labels with t(...). 31011
VenueOverviewKpiStrip.tsx (Raw camelCase Leakage)
Replaced { defaultValue: label } (which surfaced "todayReservations" and "needsAttention") with KPI_DEFAULT_LABELS: Bookings Today, Checked In Now, Active Holds, Needs Attention, and Active Resources Today. When attentionCount is undefined it renders Active Resources Today; any defined number (>= 0) renders Needs Attention. 4
VenueNav.tsx (Mismatched Fallback Label)
Updated venueNav.dashboard fallback defaultValue from "Overview" to "Dashboard" to match venue-overview.en.ts, aligning unmounted SSR/fallback rendering with the active English dictionary. 510

Minor React Compiler observation kept intact in CustomFieldListView.tsx

Commit a65306410 listed vm, vm.error, vm.items, and vm.refresh together inside the CrudConfig useMemo dependency array. We preserved that code because changing dependency structure mid-bugfix could alter hook memoization behavior, and oxlint passes with zero errors across 4243 files.2
