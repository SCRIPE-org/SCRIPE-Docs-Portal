Five fresh-context reviewers and Founder refinements locked single-pass GET /menus/navigation landing resolution, NexusLayout-unified /hub, and independent WorkManagement security fixes.1 Authorized deep links outrank enforced role landing without altering Role.Priority ceilings, while IsSystem menu slugs stay locked.2 Zero-loop error recovery, empirically measured SQL counts, and phased WorkItems widget deferral complete the build specification.3

  1. Auth handlers stay lean and return "/"; PasswordlessSessionIssuer gains ISubscriptionStatusProvider, and RefreshToken skips routing.4
  2. Removing /my-subscription and /my-plan from Workspace("admin") fixes ghost Admin tiles, rail pins, and single-module auto-launch.5
  3. Setting rootMenuItems = [] when activeWorkspaceKey === null lets /hub live inside NexusLayout cleanly.6
  4. System slug locks, custom slug cascades, Oracle UTF-8 byte checks, WorkManagement fixes, and SQL counter benchmarks harden rollout.7

How does the 6-tier precedence cascade and single bootstrap work?

Diagram structure
  • Any Admin Auth any_auth
  • Password / Billing? gate_chk
  • GET /menus/navigation nav_boot
  • LandingResolution resolve_ld
  • Deep Link / Workspace open_ws
  • Personal Home /hub open_hub
  • any_auth → gate_chk · token minted
  • gate_chk → nav_boot · clear via /
  • nav_boot → resolve_ld · 1 eval pass
  • resolve_ld → open_hub · 2+ or hub
  • resolve_ld → open_ws · redirect/1-mod

Computing landing inside GET /menus/navigation reuses one IMenuAccessEvaluator pass while / resolves Tier 1 deep links before Tier 2.1

  1. Any Admin Auth ↗

    Password, 2FA, OIDC/SAML (ExternalAdminSessionService), Magic Link, Passkey, OTP, QR, and Impersonation mint tokens and return "/"; RefreshToken skips routing.

  2. Password / Billing? ↗

    Tier 0 gates (MustChangePassword, PendingPayment) run first across all channels including PasswordlessSessionIssuer; remove localStorage.defaultRedirectPath.

  3. GET /menus/navigation ↗

    Returns AuthorizedRoutes, WorkspaceRouteMap, RouteDescriptors, WorkspaceGroups (with EffectiveHomeRoute), hydrated target menus, and LandingResolution; 500/429 renders NavigationErrorRecovery.

  4. LandingResolution ↗

    Preserves global Role.Priority; exempts Super Admins; resolves IsLandingEnforced (Tier 2), context AdminPreference (Tier 3), Role/Super default (Tier 4), and cardinality (Tier 5).

  5. Deep Link / Workspace ↗

    Entry route / checks authorized Tier 1 ?redirect= ahead of Tier 2 enforcement, then paints hydrated --workspace-hue on frame 1 without JIT delay.

  6. Personal Home /hub ↗

    Renders inside NexusLayout with activeWorkspaceKey === null (rootMenuItems = []), collapsing the secondary rail while keeping Primary Rail, Topbar, and Tenant Switcher.

What multi-DB, failure-recovery, and benchmark gates verify rollout?

  • Keep AdminPreferenceConfiguration.cs schema "identity" unchanged so Oracle does not generate destructive cross-schema RenameTable DDL.11
  • Enforce ASCII structured targets, .HasDefaultValue(false) on Role.IsLandingEnforced, UTF-8 <= 4000 bytes, and SchemaVersion = 5.
  • Reject UpdateAccountPreferences and ToggleWorkspacePin writes during impersonation ("imp" claim) with 403, and fix FeatureChecker cache thrashing.8
  • Measure SQL command counts with SqlCommandCounterInterceptor in API.IntegrationTests (baseline vs. post-refactor) before claiming query reductions.
  • Avoid retrying 401/403/429 in NavigationProvider, release the welcome curtain on routesError, and emit LandingResolutionReason metrics.
